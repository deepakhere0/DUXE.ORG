# DUXE AI Tools Promotional Video Storyboard

## Video Specifications
- **Duration**: 20-30 seconds
- **Aspect Ratio**: 16:9 (1920x1080)
- **Format**: MP4, high resolution
- **Style**: Dark modern academic UI with glowing accents
- **Primary Color**: Orange (#f9a825) for highlights
- **Background**: Dark gradient (slate/black) with particle effects

## Scene Breakdown

### Scene 1: Opening (0-3s)
**Visual**:
- Dark gradient background with subtle particle animation
- DUXE logo fades in with orange glow effect
- Subtitle appears: "AI-Powered Learning Platform"

**Animation**:
- Logo scale-in with glow pulse
- Background particles floating gently
- Typography fade-in with slide-up motion

### Scene 2: AI Summarizer (3-8s)
**Visual**:
- Document/PDF mockup appears on screen
- Text highlights with orange glow
- Document transforms into bullet-point summary with smooth animation
- UI cards slide in showing summary points

**Animation**:
- Document zoom-in effect
- Text highlight sweep from top to bottom
- Transformation with particle burst effect
- Summary cards appear with scale-in animation

**Caption**: "Summarize notes instantly"

### Scene 3: MCQ Generator (8-13s)
**Visual**:
- Study material/notes visible
- Content transforms into MCQ format
- Multiple choice options appear with A, B, C, D buttons
- Correct answer highlights with green checkmark and glow

**Animation**:
- Morphing transition from notes to MCQ layout
- Options appear with staggered slide-up
- Correct answer pulse with success animation
- Checkmark appears with scale bounce

**Caption**: "Generate MCQs automatically"

### Scene 4: Question Maker (13-18s)
**Visual**:
- Chapter/textbook content shown
- Key concepts get highlighted
- Questions generate and float as cards
- Question bank interface appears

**Animation**:
- Content scan effect with orange highlight sweep
- Questions emerge from highlighted text
- Card flip animations for question reveals
- Grid layout formation with smooth transitions

**Caption**: "Smart question creation"

### Scene 5: AI Mapping (18-23s)
**Visual**:
- Central topic node appears
- Connected concept nodes expand outward
- Mind map grows with glowing connection lines
- Interactive hover effects on nodes

**Animation**:
- Central node pulse and expand
- Branch connections draw out with orange glow
- Node scale-in with bounce effect
- Connection lines animate with flowing particles

**Caption**: "Visualize concepts with AI Mapping"

### Scene 6: All Tools Grid (23-27s)
**Visual**:
- All four tools appear in 2x2 grid layout
- Each tool icon glows in sequence
- DUXE logo in center with pulse effect
- Background particles increase intensity

**Animation**:
- Tools slide in from corners
- Sequential glow highlighting
- Logo scale pulse with orange glow
- Background particle explosion effect

### Scene 7: Closing (27-30s)
**Visual**:
- Final logo lockup
- Text overlay: "DUXE — Smarter Learning with AI Tools"
- Subtle CTA: "Get Started Free"
- Background fades to branded gradient

**Animation**:
- Logo final scale with glow
- Text fade-in with slide-up
- CTA button appears with hover state
- Background smooth fade transition

## Technical Requirements

### Color Palette
- **Primary Dark**: #0f172a (slate-900)
- **Secondary Dark**: #1e293b (slate-800)
- **Accent Orange**: #f9a825 (amber-500)
- **White Text**: #ffffff
- **Gray Text**: #94a3b8 (slate-400)
- **Success Green**: #22c55e

### Typography
- **Font**: Inter (similar to website)
- **Heading**: Bold, large sizes
- **Body**: Medium weight, readable sizes
- **Animation**: Fade-in, slide-up effects

### Animation Principles
- **Easing**: Smooth, natural motion curves
- **Timing**: 0.3-0.5s for most transitions
- **Particle Effects**: Subtle, not overwhelming
- **Glow Effects**: Soft, not harsh
- **Scaling**: Subtle scale changes (1.0 to 1.05)

### Sound Design
- **Background Music**: Modern, tech-inspired, no vocals
- **Sound Effects**: Subtle UI sounds (optional)
- **Volume**: Balanced, not overpowering

## Export Settings
- **Resolution**: 1920x1080 (Full HD)
- **Frame Rate**: 30fps
- **Bitrate**: High quality for web
- **Compression**: H.264
- **Audio**: AAC, 48kHz

## Implementation Notes

### For Motion Graphics Designer:
1. Create each scene as a separate composition
2. Use consistent timing and easing
3. Maintain brand consistency with colors
4. Test on different screen sizes
5. Include alpha channel for overlays

### For Video Editor:
1. Use smooth transitions between scenes
2. Sync animations with background music
3. Color grade for consistency
4. Add subtle particle effects overlay
5. Export multiple versions (with/without audio)

### For Web Integration:
- Optimize file size for web loading
- Create thumbnail/poster frame
- Consider autoplay policies
- Add fallback image for slow connections
- Include video controls for accessibility

## Call-to-Action Integration
The video should seamlessly integrate with the website's call-to-action:
- "Try DUXE AI Tools" button
- "Sign Up Free" messaging
- Link to `/tools` page
- Social sharing capabilities
